YOUR TASKS:

1. For every FAILED suite, read its log file from {outdir}/<suite_name>.log
   using your file read tool. Read the complete log — do not truncate.

2. For each suite log, count individual job/test outcomes:
   - COMPLETED = lines matching: Completed, CompletedWithWarnings, ✅
   - FAILED    = lines matching: RunStartFailed, Failed, CompileFailed, Aborted, NoJob, ❌, FAILED
   - completion_ratio = COMPLETED / (COMPLETED + FAILED)
   A suite with rc!=0 but completion_ratio > 0 is "partial_pass" (not a total failure).

3. Compute WEIGHTED PASS RATE:
   - passed suite        = 1.0
   - partial_pass suite  = its completion_ratio (e.g. 9/18 = 0.50)
   - failed suite        = 0.0
   - weighted_pass_rate  = sum(all weights) / total_suites * 100
