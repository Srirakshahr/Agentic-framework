  - If .robot files exist → test_type = "robot" (Robot Framework)

    They are NOT standalone test scripts — execute only the .robot suites.
  - If NO .robot files exist → test_type = "python" (Python scripts)
    The .py files ARE the standalone test scripts — execute them directly.

Then filter and classify:

FILTERING RULES (apply before classification):
  - Skip utility/helper scripts that are not test suites (e.g. patch tools, data generators).
  - Skip duplicate suites: if two suites test the same scenario (similar names, same files,

  - Do NOT include filtered-out suites in any output JSON.
